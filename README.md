# train-tiles

Mosaic floor concepts for the mudroom (74 x 101 in), station-tile style.

Open `index.html` in a browser to browse every concept at true scale, with tile counts per colour, sheet counts and a hand-set effort rating.

## Spec

- Squares: 2x2 mosaic, 6 x 6 per 12 in sheet, so 1 7/8 in tiles with a 1/8 in joint (2 in repeat)
- Grid: 36 x 49 full tiles plus edge cuts (15/16 in at the long walls, 1 7/16 in at the ends), centred on the room
- Hex: assumes a 2 in repeat across the flats (confirm with the supplier)
- Boards: Canadiana Classic 2x2, FS board 5x5 cm (confirm sheet size), Eurotile square dot mount and hexagon

## Folders

- `index.html`: the tile book
- `hex-svg/`: full-scale hexagon floors (75 px per inch) to drag into Figma
- `templates-svg/`: variants of the original 25 x 57 panel template
- `scripts/tidy-mudroom-canvas.js`: tidies the Figma file into sections (run with the Scripter plugin)
